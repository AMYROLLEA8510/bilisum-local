BiliSum

本地视频笔记工具。浏览器扩展通过 Native Messaging 与本地组件通信，不需要单独启动 BiliSum 网络服务。
第一次使用

Windows 运行 SETUP_WINDOWS.cmd；macOS 运行 SETUP_MACOS.command；Linux 运行 SETUP_LINUX.sh。安装器会先检测已有 Ollama、兼容模型和 Python 环境，只补缺少的组件。

常用功能

普通视频与合集页会保持浮窗；UP 主空间与合集支持批量整理；同一批次可合并为一个 TXT；保存目录可长期记住；无字幕视频可自动使用 Whisper 本地听写。
